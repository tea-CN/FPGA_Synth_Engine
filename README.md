# 基于 FPGA 的实时多音色合成电子乐器引擎

## 📖 项目简介
本作品是一款基于高云 FPGA (Tang Nano 20K) 的纯硬件实时电子乐器系统。系统摒弃了传统单片机软件串行计算的延迟缺陷，利用 FPGA 并行流水线优势，实现了 14 路独立 DDS 振荡器并发与硬件混音。支持左手一键和弦伴奏、右手主旋律演奏，并通过标准 I2S 接口直驱 PCM5102 DAC 芯片发声。

## ✨ 核心特性
- **纯硬件实时合成**：采用 32-bit 相位累加器（DDS），逐样本实时生成波形，无任何预录音频。
- **高复音与一键和弦**：内置和弦生成器，单键触发即可同时激活 3~4 个独立振荡器，输出华丽和弦。
- **双音色分区**：左侧键盘为三角波（柔和伴奏），右侧键盘为锯齿波（明亮主音）。
- **标准音频接口**：纯硬件生成 I2S 时序，支持 44.1kHz 采样率输出。

## 📂 目录结构
- `src/` : 所有 Verilog HDL 源码及物理约束文件
- `sim/` : 验证说明（本项目主要采用上板实测）
- `docs/` : 设计报告、系统架构图、实物照片

## 🚀 如何编译与复现
1. 打开 Gowin IDE，新建工程并选择对应器件型号。
2. 将 `src/` 目录下的所有 `.v` 文件添加至工程。
3. 添加并绑定 `src/` 下的 `.cst` 约束文件。
4. 执行综合、布局布线，并下载至 FPGA 开发板即可演奏。
